### 1.2 Выбор метода интеграции

В качеста метода интеграции был выбран **Run time**.<br>
Идея здесь заключается в том, чтобы создать группу взаимосвязанных веб-приложений, которые могут быть запущены на разных серверах, и могут обмениваться данными друг с другом через хостовое приложение.<br> 
Хостовое приложение будет объединять все эти приложения во время сборки и предоставлять пользователю единый интерфейс для работы со всеми функциями.

### 1.3 Выбор инструмента для создания микрофронтендов

| Критерий | Module-Federation | Single-SPA |
| - | - | - |
| Стек технологий | **+** <br>Единый стек, все готовые модули написаны на React.js</br> | **-** <br>Поддержка модулей написанных на разных фрейворках не требуется</br> |
| Скорость реализации | **+** <br>Небольшой плагин для сборки</br> | **-** <br>По сути сам является фреймворком, на изучение которого нужно время</br> |
| Поддержка | **+** <br>Проще поддерживать</br> | **-** <br>Есть проблемы совместимости с другими фреймворками</br> |
| Итог | **3** | **0** |

**Вывод**: на основании критериев отбора, плагин **Module-Federation** выбран для организации подхода к реализации микрофронтенд архитектруры

## Разделение монолитной системы на компоненты (микросервисы)

|id|Домен|Назначение|
| - | - | - |
| api-gateway | Службный сервис | Маршрутизация запросов от приложений, валидации JWT токена, ограничения нагрзузки на сервисы, защиты от каскадных сбоев |
| auth-service | Службный сервис | Регистрация новых пользователей, аутентификация, авторизация, назначение ролей |
| bff-admin | Службный сервис | Адаптация api backend сервисов для приложения |
| bff-customer | Службный сервис | Адаптация api backend сервисов для приложения |
| bff-support | Службный сервис | Адаптация api backend сервисов для приложения |
| message-broker | Службный сервис | Асинхронный обмен сообщениями между сервисами |
| customer-service | Сервис управления профилем клиента | Создание профиля, Редактирование профиля |
| accommodation-service | Сервис управления услугами | Создание, редактирование, удаление услуг клиента, поиск, настройка фильтрации услуг клиентов |
| product-service | Сервис управления товарами | Создание, редактирование, удаление товаров клиента, поиск, настройка фильтрации товаров клиентов |
| auction-service | Сервис управления аукционами | Создание, редактирование, обработка заявок на аукцион клиента, обновление ставок и статуса аукциона |
| market-place-service | Сервис управления торговыми площадками | Создание, поиск, настройка торговых площадок |
| order-service | Сервис управления заказами | Создание, редактирование, сохранение, подтверждение, размещение заказов клиента |
| appeal-service | Сервис управления заявками на апелляцию | Создание, редактирование, обработка статуса заявок на апелляцию |
| customer-support-service | Сервис управления заявками на техническую поддержку | Создание, редактирование, обработка статуса заявок на поддержку |
| notification-service | Сервис нотификации | Нотификация клиентов об изменении статуса: заказа, заявки на аппеляцию, заявки на поддержку, оплаты заказов |
| data-warehouse | Хранилище данных | Храниние данных, формирование отчетов, анализ данных |
